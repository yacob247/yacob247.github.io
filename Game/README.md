
Envizion Arcade
===============

This folder contains original, client-side browser games. Open `index.html` for
the game directory. The five playable projects are Meteor Dash, Word Forge,
Neon Breaker, Gridlock, and Harbor Defense.

Each game runs without an account or a game server after its page has loaded.
Best scores are stored in the browser's local storage. The games are original
small arcade projects, not copies of commercial game assets or code.
