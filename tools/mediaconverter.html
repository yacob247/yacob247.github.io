          How to use this converter

          Choose a task, add the requested files, then select Start Processing. Conversion runs in this browser; large files may take longer and the tab must remain open until the download is ready.

          For merges, add the files in the labeled panels. For trimming, use seconds and enter a duration greater than zero. Your files are not uploaded by this page.

          This page is built for quick everyday media work without sending private files to a server. Use MP4 to GIF for short looping clips, Video to MP3 when you only need the audio, Video to Images when you want frame captures in a ZIP file, and the merge tools when separate video, image, or audio inputs need to be combined. If a file is very large, wait for the progress bar to finish before changing tools or closing the tab. For best results, use clear file names, keep source files in common formats, and download the finished result before starting another conversion.
