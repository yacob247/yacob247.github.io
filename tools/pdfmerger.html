How this local PDF workflow works

This browser-based PDF workspace is designed for short, practical document jobs. Select files in the order you want them to appear, choose whether each file should be merged or downloaded separately, and then export the result. PDF files are parsed in the browser, so your source documents are not uploaded to an Envizion processing server.

Supported jobs and useful limits

The page can combine existing PDFs, turn supported Word or HTML content into a PDF, render pages as images, run OCR on image-based documents, and rasterize pages for a smaller output. OCR and image compression use more memory than a simple merge. If a large document becomes slow, work in smaller batches and close other browser tabs before trying again.

Check the output before sharing

After exporting, open the downloaded file in a PDF reader and check page order, fonts, links, image quality, and searchable text. Rasterized output may look different from the original vector PDF, and OCR results should always be proofread when the document contains names, numbers, formulas, or legal text.
