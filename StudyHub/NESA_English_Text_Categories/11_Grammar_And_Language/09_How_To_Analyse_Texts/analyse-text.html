The Universal Analysis Method

A repeatable pipeline for any text in any course.

Stage 1: Unpack the Question (Before Reading Anything)

Under exam pressure students read texts first and questions second — backwards. Do it properly:

  1. Circle directive verbs: analyse (break into parts + effects), explain (give reasons), evaluate (judge quality against criteria), compare (find similarities AND differences), discuss (present positions then take one).
  2. Box concept words: the ideas the question wants ("representation of power", "human experiences", "textual integrity").
  3. Translate to a task sentence: "I must show HOW techniques construct X and WHY that matters."

Stage 2: First Reading — Reaction Log

Read once for whole effect. Immediately jot three things: your strongest emotional response, the moment you'd call the 'turn', and one line you'd quote. This log becomes your thesis seed. If nothing surprised you, read again — surprise marks significance.

Stage 3: Annotation With a Fixed Code

Code Marks Code Marks
IMG imagery/metaphor/simile SND sound devices
SYN syntax/structure choice VO voice/pov shift
PUN punctuation as effect REP repetition/motif
TENSE tense/modality move GAP omission/absence

Rule: code only what you can already half-explain. Annotation is triage, not collection.

Stage 4: From Observations to Interpretation

List your five richest annotations side by side and ask the synthesis question: what do these have in common? The common thread is usually the text's argument about its theme. Write it as a single sentence: "Through [pattern], the text argues [claim]." That sentence is your thesis.

Worked mini-demonstration

Observations on a passage: water imagery recurs; sentences lengthen near decisions; a clock motif appears at each turning point.
Synthesis: "By tying time imagery to moments of decision, the text argues that identity is built from choices rather than circumstances." Thesis found in ninety seconds.

Stage 5: Build Paragraphs From the Interpretation Backwards

Each body paragraph = one facet of the thesis. Order them so each deepens or complicates the last (chronology of ideas beats chronology of plot). Use F-E-L per paragraph: Feature → Evidence → Effect → Link (see the Paragraphs pack).

Stage 6: Unseen Texts Strategy (Exam Speed)

  • 2 minutes: read + reaction log.
  • 3 minutes: code annotations, pick two richest.
  • 1 minute: write micro-thesis.
  • 9–12 minutes: write one sustained paragraph answering the question directly.

Budget by marks: roughly 1 minute per mark plus reading time.

Stage 7: Self-Marking Loop

After every practice response, mark against four checks: Did I answer the actual question? Is every quote explained? Does each paragraph serve the thesis? Is my expression controlled? Score /4 weekly; watch the trend, not any single score.

Medium-Specific Adjustments

  • Film: annotate stills — salience, angle, colour, sound bridge; treat shot sequence like syntax.
  • Poetry: add scansion pass (see Poetry pack).
  • Drama: read stage directions as authorial voice; imagine blocking.
  • Media/web: layout = rhetoric; headline grammar frames facts before content begins.
  • EAL/D note: the pipeline is identical; spend extra Stage-3 time building paraphrase vocabulary for effect statements.
