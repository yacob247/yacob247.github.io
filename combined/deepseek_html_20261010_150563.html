NIGHT SKY — JavaScript API

Everything in the scene is scriptable from the console or your own JS. The public object is window.NightSky.

Getting started

// The API is auto-initialised. Open the browser console and try:
NightSky.setBodyVisible('Saturn', false);
NightSky.setCameraMode('space');
NightSky.flyTo('Jupiter', { distance: 40, duration: 2 });
NightSky.light.exposure = 1.8;

Bodies

NightSky.bodies → array of { name, position, distance, radius, illuminated, altitude, visible }.

NightSky.listBodies();              // ['Sun','Moon','Mercury', ...]
NightSky.setBodyVisible('Mars', false);
NightSky.setAllBodiesVisible(false);
NightSky.getBody('Moon');
NightSky.getPosition('Moon');     // world-space [x,y,z]
NightSky.getAltitude('Venus');   // radians above horizon

Sky Layers

NightSky.setStarsVisible(false);
NightSky.setMilkyWayVisible(true);
NightSky.setGroundVisible(false);
NightSky.setBloomEnabled(true);

Lighting

All properties are plain numbers; setters clamp automatically.

NightSky.light.exposure    = 2.4;   // 0.1 – 6
NightSky.light.moonlight   = 1.6;   // 0 – 4
NightSky.light.starlight   = 1.2;   // 0 – 3
NightSky.light.skyglow     = 0.8;   // 0 – 3
NightSky.light.milkyway    = 2.0;   // 0 – 4
NightSky.light.ambient     = 0.6;   // 0 – 2
NightSky.light.bloom       = 0.75;  // 0 – 2

Time & Motion

NightSky.setTimeScale(3600);        // 1 hour of sky per real second
NightSky.pause();
NightSky.play();
NightSky.isPaused;                  // true / false
NightSky.setDate(new Date('2030-07-04T22:00:00Z'));
NightSky.setLatitude(51.5 * Math.PI/180);
NightSky.getSimTime();              // Date object

Camera

NightSky.setCameraMode('space');      // 'ground' | 'space'
NightSky.setFieldOfView(35 * Math.PI/180);
NightSky.lookAt('Mars');
NightSky.flyTo('Moon', {
  distance: 25,       // world units from target
  duration: 1.5       // seconds of ease-in-out
});
NightSky.unfollow();
NightSky.camera.position;            // [x,y,z] world units
NightSky.camera.forward;             // unit vector

Events

NightSky.on('tick', ({ time, camera, bodies }) => {
  // called every frame — do your own HUD here
});
NightSky.on('bodyVisibility', ({ name, visible }) => { ... });
NightSky.off('tick', myHandler);

Keyboard

H           toggle control panel
J           toggle this documentation
G           switch ground ⇄ space camera
W A S D     fly forward / left / back / right
Q / E       fly down / up
Shift       boost speed ×6
1 – 8       lock camera on Mercury → Neptune
9           lock on Moon
0           lock on Sun
F           free look (unfollow)
Space       pause / resume time
+ / −       double / halve time speed
Drag        look around
Wheel       zoom (field of view)
