About Arrow Escape

Arrow Escape is a clean, logic-based puzzle game where you tap arrows to clear the board without causing collisions. With its satisfying feedback and increasing complexity, it is a great game for players who enjoy quick, thoughtful puzzles.

How to play

Each arrow on the board points in a direction. Tap an arrow to launch it in its direction. If its path is blocked by another arrow, it will collide. Plan your taps so every arrow escapes the board without colliding. Levels get harder as you progress, adding more arrows and tighter layouts.

Game modes

Single-player logic puzzle with progressively harder levels.

Tips and tricks

  1. Start with arrows that have clear paths.
  2. Look for chains of arrows that can escape together.
  3. Undo if possible rather than restarting.
  4. Take your time — speed is not the goal.
