About Prism Sort

Prism Sort is a colorful sorting puzzle where you pour colored balls between tubes to organize them by color. With its satisfying mechanics and escalating complexity, it is a soothing yet challenging puzzle game.

How to play

Each tube contains a mix of colored balls. Your goal is to sort them so each tube contains only one color. You can pour the top ball from one tube into another if there is space and the colors match or the target is empty. Plan your pours carefully to avoid getting stuck.

Game modes

Single-player sorting puzzle with progressive levels.

Tips and tricks

  1. Empty tubes are valuable — keep one open.
  2. Plan several pours ahead.
  3. Do not fill a tube with the wrong color.
  4. Restart if you get truly stuck.

Features

  • Color sorting puzzle gameplay.
