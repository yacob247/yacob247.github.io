About Ninefold

Ninefold is a tile-dropping puzzle game where you place blocks on a 9×9 grid to clear rows and columns. With its satisfying combo system and simple controls, it is a great game for quick sessions and high-score chasing.

How to play

Drag blocks onto the 9×9 grid. When a row or column is completely filled, it clears and scores points. Blocks come in different shapes, so plan placements carefully. If there is no room for the current block, the game ends. Chain clears for big combos.

Game modes

Single-player tile puzzle with score chasing.

Tips and tricks

  1. Keep space open for large blocks.
  2. Aim for multiple clears at once.
  3. Avoid filling one row too early.
  4. Plan two or three moves ahead.

Features

  • Tile-dropping puzzle gameplay.
  • 9×9 grid with row and column clears.
  • Score chasing and combos.
