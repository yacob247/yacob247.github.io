About Falstad Circuit Simulator

Falstad Circuit Simulator is a powerful, interactive electronic circuit simulator that runs in your browser. Build circuits, test components, and see current flow in real time. It is an invaluable tool for students, hobbyists, and anyone interested in electronics.

How to play

Drag components onto the workspace to build a circuit. Connect them with wires and adjust values like resistance and voltage. The simulator shows current flow with animated dots and calculates voltages and currents. You can test and modify circuits on the fly. It is a sandbox for learning and experimenting with electronics.

Game modes

Single-player interactive circuit simulation.

Tips and tricks

  1. Start with simple circuits before building complex ones.
  2. Use the built-in examples to learn the interface.
  3. Watch current flow animations to understand behavior.
  4. Adjust component values one at a time to see effects.

Features
