About Depot

Depot is a classic crate-pushing puzzle game in the Sokoban style. Push every crate onto its target pad without getting stuck. Simple rules, satisfying logic, and increasingly tricky levels make it a timeless puzzle experience.

How to play

Move your character around the grid and push crates onto target pads. You can only push one crate at a time and cannot pull them, so plan carefully. If a crate gets stuck in a corner, you may need to restart. Complete each level to move on to the next, more difficult puzzle.

Game modes

Single-player Sokoban-style puzzle with progressive levels.

Tips and tricks

  1. Plan several moves ahead before pushing.
  2. Avoid pushing crates into corners.
  3. Use undo rather than restarting.
  4. Start with the most constrained crates.

Features

  • Classic crate-pushing puzzle gameplay.
  • Progressive difficulty.
  • Simple controls with deep logic.
