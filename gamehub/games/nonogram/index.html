About Nonogram

Nonogram is a logic puzzle where you use number clues to reveal a hidden picture. Fill in the correct cells to uncover the image, using deduction rather than guessing. With its elegant system and satisfying reveals, it is a classic for puzzle fans.

How to play

Each row and column has number clues indicating how many filled cells appear in that line, in order. Use logic to determine which cells are filled and which are empty. When solved correctly, the filled cells reveal a picture. Levels range from small and easy to large and complex.

Game modes

Single-player logic puzzle with many picture levels.

Tips and tricks

  1. Start with rows and columns with large numbers.
  2. Mark confirmed empty cells to constrain other clues.
  3. Never guess — logic always gives a solution.
  4. Use the fill-multiple tool for speed.

Features
