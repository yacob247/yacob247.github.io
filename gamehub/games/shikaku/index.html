About Shikaku

Shikaku is a logic puzzle where you divide a grid into rectangles that match the given numbers. Each number must be enclosed in a rectangle of exactly that area. With its elegant rules and satisfying solutions, it is a great brain-teaser for puzzle fans.

How to play

Each number on the grid indicates the area of a rectangle. Draw rectangles to divide the entire grid, ensuring each rectangle contains exactly one number and its area matches the number. Rectangles cannot overlap. Solve the grid using logic and deduction.

Game modes

Single-player logic puzzle with daily and progressive levels.

Tips and tricks

  1. Start with the largest numbers.
  2. Corner numbers have limited rectangle options.
  3. Use overlapping constraints to rule out shapes.
  4. Do not guess — logic always leads to a solution.
