Data sources and what they cover

Nager.Date public holiday API

Public, bank, school and observance holiday types across 200+ supported countries; country/year records.

OpenHolidays API

Public and official school holidays by supported country, plus public/school holiday lookups from supported countries for a given date.

United Nations observance list

Official UN international days and weeks. This file includes a small recurring-date seed; use the UN list for the full official catalogue.

AlAdhan Islamic calendar API

Calculated Hijri calendar dates for Ramadan and Eid. Its calculation method and local sighting announcements can differ.
