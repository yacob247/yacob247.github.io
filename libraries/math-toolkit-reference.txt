MATHEMATICS TOOLKIT REFERENCE
For the browser calculator running Python in Pyodide 0.26.4.

This is a guide to the available tools, not a formula encyclopedia. Use the
task wording and any provided source to decide what the problem means. Search
for a definition, convention, or formula when it is specialized, ambiguous,
curriculum-specific, or not confidently known. Read the relevant source before
choosing the method. Then write a short, checkable plan, calculate, and verify.
Do not search the web for plain arithmetic whose meaning is already clear.

AVAILABLE PYTHON TOOLS

Built-in exact arithmetic
- int: exact whole-number arithmetic, including very large integers.
- fractions.Fraction: exact fractions and rational percentages.
- decimal.Decimal: money and decimal rounding; construct from strings.
- math and statistics: common real-number functions and basic descriptive
  statistics. math functions use radians.

SymPy (import sympy as sp)
- Symbolic algebra, exact expressions, equation and inequality solving,
  calculus, matrices, number theory, combinatorics, geometry, logic, and
  selected physics and statistics tools.
- Create symbols explicitly. Use sp.Eq for equations and select a domain for
  solving when the real/complex domain changes the answer. Inspect the result;
  a solver may return a set, condition, or no closed form.
- Use exact integers, Rational, and symbolic constants when exactness matters.
  Use evalf only when a decimal approximation is requested or useful.
- SymPy computes a mathematical expression; it does not determine what a
  word problem means or choose the correct real-world assumptions for you.

NumPy (import numpy as np)
- Arrays, vectorized numeric calculations, and linear algebra on numeric data.
- Prefer Python integers/Fraction/SymPy when exact arithmetic is required;
  many NumPy operations use fixed-width or floating-point values.

SciPy (import scipy; use the relevant scipy submodule)
- Numerical methods such as optimization, integration, interpolation,
  statistics, signal processing, sparse matrices, and special functions.
- Results are often approximations. Check convergence, domains, units, and
  tolerances; do not present a numerical approximation as an exact result.

Other available specialist packages
- mpmath: arbitrary-precision numerical evaluation and special functions.
- pandas: tabular data and data analysis.
- statsmodels: statistical models and regression.
- uncertainties: calculations that propagate measurement uncertainty.
- unyt: physical quantities with units and unit-aware conversions.
- matplotlib: charts; save charts with plt.savefig in /mnt/data.
- Pyodide 0.26.4 also includes packages such as scikit-learn and astropy;
  check the official package list before relying on a less common package.

HOW TO CHOOSE AND CHECK A METHOD

1. Parse the request: identify what is asked, every given value, units, time
   order, and what each percentage or rate applies to.
2. Look up unfamiliar terminology and any formula convention that matters.
   Prefer the user's attached source, official curriculum material, package
   documentation, university/open textbooks, or NIST references. Check the
   source supports this exact interpretation; a search result title is not
   enough.
3. Make a short plan naming quantities and their relationships before
   calculating. State a material assumption or ask if multiple meanings
   produce different answers.
4. Select the lightest suitable tool: built-in exact arithmetic for ordinary
   numbers; SymPy for symbolic/exact algebra; SciPy for numerical methods;
   NumPy/pandas for numeric arrays and data. Do not import every package.
5. Define every variable before use. Keep intermediate quantities named and
   print the requested outputs with units and clear labels.
6. Verify independently where practical: substitute solutions back into the
   original equation, check dimensions and bounds, compare a second method,
   or check a conservation/accounting identity. Explain what was checked.
7. Base the answer on Python's actual output. Keep exact digits intact; round
   only when the question or a stated convention requires it.

LIMITS

No computer algebra package can infer a missing definition, unstated rate
base, or intended interpretation with certainty. Do not invent one. If a
source cannot be reached or evidence conflicts, say so and ask for the needed
clarification. Python in the browser needs an internet connection to fetch
Pyodide packages that have not yet loaded; loaded packages are reused in that
browser session.
