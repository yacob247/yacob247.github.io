MATHEMATICS SOURCE DIRECTORY
Trusted starting points for lookup. This is a source list, not a compiled
formula sheet. Search for the exact topic and cite the page actually used.

School and university mathematics
- OpenStax free math textbooks, from prealgebra through calculus and statistics:
  https://openstax.org/k12/math
  https://openstax.org/new-subjects/math-books
- Current NESA Mathematics Advanced and Extension 1/2 HSC Reference Sheet page:
  https://www.nsw.gov.au/education-and-training/nesa/curriculum/hsc-exam-papers/mathematics-advanced-extension-reference-sheet
  NESA lists this as a formula/reference sheet, published 1 January 2025.
- NESA Mathematics and Mathematics Extension 1/2 HSC Reference Sheet purpose
  and development principles:
  https://educationstandards.nsw.edu.au/wps/wcm/connect/ebb2d27f-6635-4cbc-aa65-644eb118d69e/reference-sheet-development-principles.pdf?MOD=AJPERES
  This describes the NSW Stage 6 Mathematics and Extension courses; the sheet
  is a memory aid and does not define its terms. Check the user's course and
  current syllabus before applying it.
- NESA Mathematics Standard 1 and 2 Reference Sheet purpose and principles:
  https://educationstandards.nsw.edu.au/wps/wcm/connect/324e00e2-d8b1-4104-be75-98c87ed8c5b1/mathematics-standard-2017-1-and-2-reference-sheet-purpose-and-development-principles.docx?CVID=&MOD=AJPERES
  This document describes the 2017 Standard courses; verify current course
  materials before applying it.
- NESA Mathematics Standard 1/2 Stage 6 page, which points to its reference
  sheet and notes the newer 2024 syllabus:
  https://www.nsw.gov.au/education-and-training/nesa/curriculum/mathematics/mathematics-standard-stage-6-2017

Lookup rules
- Prefer the exact source named by the user, an official curriculum authority,
  official software documentation, NIST, or a reputable open textbook.
- Check level, course, domain, units, assumptions, and version. Similar names
  can refer to different conventions.
- Search results are leads; open and read the supporting source before using a
  formula. Do not invent a citation or claim a page was read when it was not.
- Show the user the sources actually retrieved for a calculation. If a lookup
  fails or sources disagree, say so and ask for the needed context.
