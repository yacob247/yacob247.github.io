How to link the two CSS files in your HTML
html
<link rel="stylesheet" href="/assets/css/classic.css">
<link rel="stylesheet" href="/assets/css/motion.css">
Order matters — classic.css first, motion.css second (so animations can use the --t-base, --c-primary variables defined in classic.css).

These are the files you'll create using the templates from my reference .txt files. Names below are exact — case-sensitive on Linux hosts.

🔹 Static assets folder (pick one convention and stick to it)
I recommend /assets/ with subfolders:

text
/assets/
├── css/
│   ├── classic.css             ← my file #1
│   └── motion.css              ← my file #2
├── js/
│   └── app.js
├── img/
│   └── (all your images)
├── icons/
│   ├── favicon-16.png
│   ├── favicon-32.png
│   ├── favicon-48.png
│   ├── apple-touch-icon.png    (180×180)
│   ├── icon-192.png            (PWA)
│   ├── icon-512.png            (PWA)
│   ├── icon-maskable-512.png   (PWA)
│   ├── mstile-150.png          (Windows tile)
│   └── safari-pinned-tab.svg
└── fonts/
    └── (woff2 files)
The /favicon.ico still goes at root, not in /assets/icons/ — that's the one exception where browsers look in the old default location.
