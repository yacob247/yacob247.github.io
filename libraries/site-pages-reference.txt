================================================================================
 SITE-PAGES-REFERENCE.TXT
 A complete catalog of every page that can exist on a website.
 --------------------------------------------------------------------------------
 This is NOT a fixed structure. It is a MENU.
 Read through, pick what you need, ignore the rest.
 Grouped by website type + cross-cutting universal categories.
 Every page is listed once in its "home" category, with cross-references
 where a page is commonly reused.
================================================================================


================================================================================
 SECTION 0 · READ ME FIRST
================================================================================

HOW TO USE THIS FILE
  · Skim the section headers.
  · Under each section, tick the pages you want.
  · Anything marked [CORE] is almost always needed.
  · Anything marked [OPTIONAL] is nice-to-have.
  · Anything marked [ADVANCED] needs backend / database / accounts.
  · Anything marked [LEGAL] should exist if you collect data or sell.
  · Every page gets its own detail block: purpose, must-have sections,
    optional sections, common variants.

FILE / URL NAMING CONVENTIONS (suggestions, not rules)
  /                    → home
  /about               → about
  /contact             → contact
  /pricing             → pricing
  /blog                → blog index
  /blog/post-slug      → single post
  /products            → product index
  /products/item-slug  → single product
  /legal/privacy       → privacy policy
  Nested paths are fine but keep URLs short, lowercase, hyphenated.

PAGE ANATOMY (every page should be built from these zones)
  · Header / Navbar
  · Hero or Page Title band
  · Main content region
  · Sidebar (optional)
  · Call-to-action band (optional)
  · Footer
  · Global overlays: cookie notice, modal, toast, chat widget

 SECTION 1 · UNIVERSAL PAGES  (needed by almost every site)
================================================================================

1.01  HOME                                   [CORE]
      Purpose: the front door. Orient a visitor in 3 seconds.
      Must have:  hero, value proposition, primary CTA, social proof,
                  featured content, navigation.
      Optional:   latest posts, featured products, newsletter signup,
                  testimonial carousel, stats band, logos of clients.
      Variants:   landing page, long-form home, app-download home,
                  one-pager home, coming-soon home.

1.02  ABOUT / ABOUT US                       [CORE]
      Purpose: build trust — who you are, why you exist.
      Must have:  mission, story, team / founder, values, contact link.
      Optional:   timeline, photos, press mentions, awards, office map.
      Variants:   about-me (personal), about-company (business),
                  about-team, about-project, manifesto page.

1.03  CONTACT                                [CORE]
      Purpose: let people reach you.
      Must have:  contact form, email/phone, address (if physical),
                  map embed (optional), social links.
      Optional:   office hours, multiple locations, department routing,
                  file upload, booking link, WhatsApp/Telegram link.
      Variants:   simple form, split layout, map-first, multi-location.

1.04  PRICING                                [CORE if selling anything]
      Purpose: show cost clearly and drive conversion.
      Must have:  tier table, what's included, CTA per tier, FAQ.
      Optional:   toggle monthly/yearly, comparison table, enterprise CTA,
                  currency switcher, testimonials per tier.
      Variants:   card pricing, comparison table, calculator, quote-request.

1.05  FAQ / HELP CENTER                      [CORE]
      Purpose: answer repeat questions without support tickets.
      Must have:  categorised questions, search, contact fallback.
      Optional:   accordion UI, video answers, article links, feedback vote.
      Variants:   single FAQ, multi-category help center, chatbot-first.

1.06  404 NOT FOUND                          [CORE]
      Purpose: catch broken URLs gracefully.
      Must have:  message, search, home link, nav links.
      Optional:   suggestions, fun illustration, report link.
      Variants:   friendly 404, minimal 404, redirect-after-countdown.

1.07  500 / SERVER ERROR                     [CORE]
      Purpose: catch server faults gracefully.
      Must have:  message, retry link, home link, contact link.

1.08  SEARCH RESULTS                         [CORE if searchable]
      Purpose: show site search results.
      Must have:  query echo, result list, empty state, refine controls.
      Optional:   filters, sort, pagination, "did you mean".

1.09  SITEMAP (HTML)                         [CORE]
      Purpose: human-browsable map of the site.
      Must have:  grouped links to every public page.

1.10  NEWSLETTER SIGNUP / THANK YOU          [OPTIONAL]
      Purpose: capture emails and confirm.
      Must have:  form or confirmation message, next step, unsubscribe.
      Variants:   inline, popup, full-page, double-opt-in confirm.

1.11  COMING SOON / LAUNCH HOLD              [OPTIONAL]
      Purpose: pre-launch teaser.
      Must have:  headline, signup form, social links.

1.12  MAINTENANCE                            [OPTIONAL]
      Purpose: explain downtime.
      Must have:  message, ETA, contact, status link.

1.13  SIGN IN / LOG IN                       [ADVANCED]
      Purpose: authenticate users.
      Must have:  email/password, forgot link, signup link, error states.
      Optional:   SSO, magic link, 2FA, "remember me".

1.14  SIGN UP / REGISTER                     [ADVANCED]
      Purpose: create an account.
      Must have:  fields, terms checkbox, verification flow, error states.
      Optional:   social login, invite code, onboarding wizard.

1.15  FORGOT PASSWORD / RESET                [ADVANCED]
      Purpose: recover accounts.
      Must have:  email field, sent confirmation, new password form.

1.16  VERIFY EMAIL / CONFIRM ACCOUNT         [ADVANCED]
      Purpose: prove the address is real.

1.17  ACCOUNT / PROFILE (dashboard)          [ADVANCED]
      Purpose: user self-service.
      Must have:  profile info, password, email prefs, delete account.
      Optional:   orders, invoices, downloads, saved items, API keys.

1.18  LOG OUT / GOODBYE                      [ADVANCED]
      Purpose: confirm the sign-out.

1.19  PRIVACY POLICY                         [LEGAL]
      Purpose: explain what data you collect and why.
      Must have:  what, why, how long, who, your rights, contact.
      Variants:   short, full GDPR, CCPA appendix.

1.20  TERMS & CONDITIONS                     [LEGAL]
      Purpose: legal ground rules.
      Must have:  use rights, liability, IP, termination, governing law.

1.21  COOKIE POLICY / PREFERENCES            [LEGAL]
      Purpose: explain cookies and let users opt in/out.
      Must have:  categories, toggle, save, accept all, reject all.
      Optional:   per-vendor list, log download.

1.22  ACCESSIBILITY STATEMENT                [LEGAL]
      Purpose: declare accessibility commitment and level.

1.23  DISCLAIMER / IMPRINT                   [LEGAL]
      Purpose: legal disclosure (esp. EU/Germany).

1.24  CHANGELOG / WHAT'S NEW                 [OPTIONAL]
      Purpose: document product changes.

1.25  STATUS PAGE                            [OPTIONAL]
      Purpose: uptime and incident history.

1.26  ROADMAP / FEEDBACK                     [OPTIONAL]
      Purpose: public roadmap, upvote ideas, submit.

1.27  PRESS / MEDIA KIT                      [OPTIONAL]
      Purpose: logos, photos, facts for journalists.

1.28  BRAND / STYLE GUIDE                    [OPTIONAL]

 SECTION 22 · HOW TO DECIDE WHAT TO BUILD
================================================================================

STEP 1 · Ask: "What does the visitor want on each page?"
  If you can't name it in one sentence, the page is probably
  not needed or should be merged.

STEP 2 · Ask: "What action should this page drive?"
  Every page needs at least one action: read, click, buy, donate,
  subscribe, contact, share. If there is no action, delete the page.

STEP 3 · Ask: "Can this be a section of an existing page?"
  Many pages in this list are nice-to-haves that work fine as a
  section on the home or about page. Start with fewer pages.

STEP 4 · Ask: "Is this legal or trust-critical?"
  Privacy, Terms, Cookies, Accessibility, 404, Contact — always.

STEP 5 · Ask: "Is this advanced or core?"
