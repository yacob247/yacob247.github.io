⚙️ One-time setup required

To match real people across the internet, this app needs a signaling channel. Firebase Realtime Database is free and needs no server of your own.

  1. Go to console.firebase.google.com → Add project.
  2. Build → Authentication → Sign-in method → enable Google.
  3. Build → Realtime Database → Create Database (test mode is fine to start).
  4. Rules tab → paste the rules from the code comments.
  5. Project settings → Your apps → Web → copy the firebaseConfig.
  6. Paste it into firebaseConfig at the top of the <script> in this file.
  7. Under Authentication → Settings → Authorized domains, add the domain you host this on.
