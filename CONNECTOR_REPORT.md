## AI Invocation Pattern (summary)
1. Load tool page in iframe: `iframe.src = "/tools/<tool-name>.html"`
2. On `iframe.onload`, access `win = iframe.contentWindow`, `doc = iframe.contentDocument`.
3. Set inputs: locate inputs by id/name, set `.value` or use `DataTransfer` for files.
4. Trigger: either `win.<functionName>(...)` or `button.click()` where button is from the trigger map above.
5. Read result: check `doc.querySelector("#output")`, canvas elements, `<a download>` links, or global variables.
